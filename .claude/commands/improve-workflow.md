# Improve n8n Workflow

Analyse le fichier `workflows/n8n-affiliate-workflow.json` et propose des améliorations concrètes.

1. Lis le contenu complet du workflow avec `cat workflows/n8n-affiliate-workflow.json`
2. Identifie les nœuds qui pourraient être optimisés
3. Propose **exactement 5 améliorations** classées par impact (haute/moyenne/basse priorité) :
   - Résilience et gestion d'erreurs (retry, fallback)
   - Performance (parallélisation, cache)
   - Qualité du contenu généré (prompt engineering)
   - Monitoring et observabilité
   - Sécurité (gestion des secrets, rate limiting)

Pour chaque amélioration, indique :
- Le nœud concerné
- Le problème actuel
- La solution proposée
- L'effort d'implémentation estimé (faible/moyen/élevé)

Ne modifie pas le fichier — génère uniquement l'analyse et les recommandations.
